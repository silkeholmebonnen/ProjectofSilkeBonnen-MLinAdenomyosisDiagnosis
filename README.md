# Project of Silke Bonnen - ML in Adenomyosis Diagnosis

This is a research project taking place at the IT University of Copenhagen in the spring of 2026.
It is a literature review following the PRISMA guidelines.

## Repository structure
- The `notebooks` directory contains the relevant notebooks.
- The `literaure` directory contains the csv files exported from IEEE, lens.org and PubMed.
- The `filtered_papers` directory contains the csv file with the results of the filtering from the notebooks files, called filtered-papers. It also contains a similar csv file called filtered-papers_manual_post_filtering, that includes 2 columns, one column indicating if the articles was included in the PRISMA review, and one column explaning the reason for exclusion in the PRISMA review.
